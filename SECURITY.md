# Security

Please report security issues privately by emailing support@lumyforynab.app.

Do not open a public issue for vulnerabilities, leaked credentials, or account/data access problems.

When reporting, include:

- Affected component.
- Steps to reproduce.
- Impact and scope.
- Any relevant logs or screenshots with personal data removed.

Lumy should not contain production secrets, signing keys, store credentials, or private deployment configuration in this public repository.
