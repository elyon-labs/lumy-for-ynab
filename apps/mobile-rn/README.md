# Lumy mobile (React Native)

The Expo client that replaces the Flutter app in `apps/mobile`.

Dependencies are installed from the repository root, which is the pnpm
workspace root:

```sh
pnpm install
pnpm mobile:start
```

| Command | Purpose |
| --- | --- |
| `pnpm mobile:start` | Expo dev server |
| `pnpm mobile:ios` | Build and run on an iOS simulator |
| `pnpm mobile:ios:device` | Build and run on a connected iOS device |
| `pnpm mobile:android` | Build and run on an Android emulator or device |
| `pnpm mobile:typecheck` | `tsc --noEmit` |
| `pnpm mobile:lint` | ESLint via `expo lint` |
| `pnpm mobile:test` | vitest |

`ios/` and `android/` are generated by prebuild and are not committed.

Routes live in `src/app` and are file-based via `expo-router`. Everything else
is organised by domain under `src/`, not by layer.
